Все статьи вики пишутся обычным текстом с разметкой. Почти всё вставляется кнопками на панели редактора, а на этой странице разобран весь набор: слева то, что вы пишете, справа то, что увидят читатели.

> Правка попадает к администрации и появляется на сайте после проверки. Статус своих правок видно на странице [Мои правки](/wiki/my).

# Текст

:: **Жирный текст**
:: *Курсив*
:: ==Акцент==
:: `Код или команда`

Чтобы разметка не сработала, поставьте перед знаком обратный слэш: `\*не курсив\*`.

# Заголовки

Заголовок начинается с решётки и пробела. Чем больше решёток, тем он мельче. Заголовки сами попадают в содержание статьи.

```
# Большой раздел
## Подраздел
### Мелкий заголовок
```

# Списки

Обычный список начинается со знака минус и пробела:

:: - Первый пункт

Нумерованный начинается с цифры и точки:

:: 1. Первый шаг

# Ссылки

Ссылка на статью вики начинается со слэша:

:: [Банк и счета](/wiki/bank)

Внешняя ссылка пишется полностью и открывается в новой вкладке:

:: [Сайт сервера](https://mistraly.net)

# Ссылка на игрока

Напишите @ и ник: рядом появится голова со скином, а ссылка откроет страницу игрока. В редакторе после @ всплывает подсказка с никами.

:: @NioRio

Отдельная голова без ссылки вставляется так, последнее число задаёт размер:

:: <avatar/NioRio/32>

# Автоссылки

Названия механик и предметов сами становятся ссылками: на странице подсвечивается первое упоминание, падежи учитываются. Автоссылка не ставится внутри жирного текста и на собственной странице.

:: Положите мисты на счёт

Чтобы слово не стало ссылкой, поставьте перед ним восклицательный знак, он не отобразится:

:: !Мист как обычное слово

# Карточки

Строка со знака > становится карточкой:

:: > Важная подсказка для читателя

Несколько карточек в ряд: каждый новый знак > начинает колонку. Колонок может быть до пяти.

:: > Левая карточка > Правая карточка

Вся карточка живёт в одной строке, перенос внутри пишется как `\n`, а `>>` добавляет внутреннюю подсказку:

:: > ### Заголовок \n 1. Первый шаг \n 2. Второй шаг \n >> Примечание

# Таблицы

Строки таблицы начинаются и заканчиваются вертикальной чертой, первая строка становится шапкой:

```
| Предмет | Урон |
| Меч | 8 |
| Нож | 5 |
```

| Предмет | Урон |
| Меч | 8 |
| Нож | 5 |

# Предметы и рецепты

Предмет в тексте с иконкой и ссылкой на статью:

:: <item/mistraly:mist>

Ряд предметов, идентификаторы через пробел:

:: <items/mistraly:mist mistraly:mist_shard mistraly:raw_mist>

Цепочка добычи: > ведёт к следующему шагу, + добавляет предмет рядом, *6 задаёт количество:

:: <flow/mistraly:mist_ore > mistraly:raw_mist + mistraly:raw_mist_shard*2>

Все рецепты предмета:

:: <recipes/mistraly:atm>

# Сноска справа

Блок справа от текста, как у [Мист](/wiki/mist), собирается отдельными строками в начале статьи:

```
<icon/mistraly:mist>
<info/Тип/валюта>
<info/Делится на/9 осколков>
```

В конце статьи можно перечислить похожие страницы:

```
<see/bank atm ores>
```
